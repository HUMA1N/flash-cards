# flash-cards

Карточки для заучивания с интервальными повторениями по алгоритму SM-2. Обычный статический сайт: без сервера, регистрации, сборки и зависимостей. Всё хранится в браузере, тёмная тема, удобно с телефона.

## Возможности

- **Колоды** с названием и описанием, карточки «вопрос — ответ», поиск по колоде.
- **Добавление списком**: вставьте строки `термин — определение`, и каждая строка станет карточкой. Разделителем может быть тире (—, –, -), табуляция (при копировании из Excel или Google Таблиц), `;`, `:` или `=`. Перед добавлением показывается превью и строки, которые не удалось разобрать. Нумерацию и маркеры списка в начале строк программа убирает сама, повторы пропускает.
- **Повторение по SM-2** с кнопками «Не помню», «Трудно» и «Легко». Под каждой кнопкой написано, когда карточка вернётся. Последний ответ можно отменить.
- **Тренировка**: прогон всех карточек колоды вперемешку без влияния на расписание. Удобно перед контрольной.
- **Лимит новых карточек в день** (по умолчанию 20 на колоду), чтобы повторения не копились лавиной.
- **Тест**: вопрос и 4 варианта ответа, один верный. Неверные варианты берутся из других карточек колоды (похожей длины, чтобы правильный не бросался в глаза). В конце — процент, список ошибок и кнопка «Повторить ошибки». Расписание SM-2 тест не меняет. Число вопросов (по умолчанию 20) задаётся в «Настройках».
- **Импорт из Quizlet**: в Quizlet «…» → «Экспортировать» → «Копировать текст», вставить в «Импорт → Вставить текст из Quizlet». Разделители (табуляция/запятая, перенос строки/точка с запятой) определяются сами, можно указать свои.
- **Импорт CSV**: файл `.csv` или вставка таблицы. Понимает кавычки, переносы строк внутри значений, разделители `,` `;` и табуляцию, заголовок «Вопрос,Ответ» / «term,definition». Лишние колонки попадают в пояснение. Карточки можно добавить в новую или в существующую колоду, повторы пропускаются.
- **Статистика** (кнопка с графиком вверху): серия дней подряд и рекорд, календарь занятий за год как на GitHub, сколько карточек выучено, изучается и ещё не начато — всего и по каждой колоде.
- **Экспорт и импорт** колод в файл: резервная копия с прогрессом, файл «только карточки», чтобы поделиться, текстовый список или таблица `.csv`.
- **Приложение на телефоне (PWA)**: кнопка «Установить» на главной или в «Настройках»; на iPhone — «Поделиться» → «На экран „Домой“». После первого открытия сайт работает без интернета.

## Запуск

- **Локально**: откройте `index.html` в браузере. Всё работает и без сервера, кроме офлайн-режима.
- **С локальным сервером**: `npm start` (или `python3 -m http.server`), затем откройте http://localhost:8000.
- **GitHub Pages**: публикует GitHub Actions (`.github/workflows/pages.yml`) при каждом изменении ветки `main`. Один раз включите в репозитории **Settings → Pages → Build and deployment → Source: GitHub Actions**. Сайт появится по адресу `https://<пользователь>.github.io/flash-cards/`. Его можно открыть с телефона и установить на главный экран.

### Запуск на Windows для новичка

1. Скачайте проект: на странице репозитория зелёная кнопка **Code → Download ZIP**, распакуйте архив.
2. Дважды щёлкните `index.html` — сайт откроется в браузере. Так работает всё, кроме установки и офлайн-режима.
3. Чтобы проверить и их, поставьте [Node.js](https://nodejs.org/) (версия LTS), откройте папку проекта, в адресной строке Проводника наберите `cmd` и нажмите Enter. В открывшемся окне выполните `npm start` и откройте http://localhost:8000.
4. Тесты: в том же окне `npm test`.

## Как работает повторение (SM-2)

Каждая кнопка соответствует оценке качества ответа `q` по шкале SM-2:

| Кнопка | q | Что происходит |
|---|---|---|
| Не помню | 1 | счётчик повторений и интервал сбрасываются (интервал — 1 день), лёгкость уменьшается на 0,54; карточка ещё раз покажется в этой же сессии |
| Трудно | 3 | интервал растёт, лёгкость уменьшается на 0,14 |
| Легко | 5 | интервал растёт, лёгкость увеличивается на 0,1 |

При успешном ответе интервал равен 1 дню после первого повторения, 6 дням после второго, а дальше `предыдущий интервал × EF`. Коэффициент лёгкости EF вначале равен 2,5 и не опускается ниже 1,3. Формула: `EF' = EF + (0,1 − (5 − q)(0,08 + (5 − q)·0,02))`.

Расписание меняется только от первого ответа на карточку в сессии. Повторные показы после «Не помню» служат закреплению, как и предписывает SM-2.

## Данные, экспорт и импорт

Колоды и прогресс лежат в `localStorage` браузера (ключ `flashcards.v1`), только на этом устройстве. Формат данных при обновлениях не меняется, сохранённые колоды остаются на месте; журнал занятий для статистики — поле `log` (`{"ГГГГ-ММ-ДД": число ответов}`). Чтобы перенести их на другое устройство или не потерять при очистке браузера, сохраняйте резервную копию через «Экспорт».

Формат файла экспорта:

```json
{
  "format": "flash-cards",
  "version": 1,
  "decks": [
    {
      "id": "…",
      "name": "Название",
      "description": "",
      "cards": [
        { "q": "Вопрос", "a": "Ответ", "ef": 2.5, "n": 0, "interval": 0, "due": null }
      ]
    }
  ]
}
```

Импорт понимает такой файл, а также упрощённые варианты:

- одну колоду `{ "name": "…", "cards": [...] }`;
- массив колод;
- массив карточек `[{ "q": "…", "a": "…" }]` или `[["вопрос", "ответ"]]`. Поля можно называть и `question`/`answer`, и `front`/`back`, и `term`/`definition`;
- текстовые файлы `.txt`, `.csv` и `.tsv`, где каждая строка — «вопрос — ответ». Поддерживаются кодировки UTF-8 и Windows-1251.

Если колода с таким же `id` уже есть, сайт спросит, заменить её или добавить копию.

В тексте карточки всё, что идёт после пустой строки, показывается мелким шрифтом как пояснение.

## Структура

```
index.html            разметка-каркас
css/style.css         стили (тёмная тема, mobile-first)
js/sm2.js             алгоритм SM-2 и даты
js/parse.js           разбор списка «термин — определение»
js/data.js            модель данных, очередь, статистика, экспорт/импорт
js/importer.js        разбор текста Quizlet и CSV
js/quiz.js            режим «Тест»: 4 варианта ответа
js/stats.js           календарь занятий, серии, итоги по карточкам
js/samples.js         колоды-примеры
js/app.js             интерфейс
sw.js                 офлайн-кэш (service worker)
manifest.webmanifest  установка на главный экран
tests/                тесты логики (node:test)
.github/workflows/    тесты на каждый push и публикация на GitHub Pages
```
