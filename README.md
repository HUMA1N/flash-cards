# flash-cards

Карточки для заучивания с интервальными повторениями по алгоритму SM-2. Обычный статический сайт: без сервера, регистрации, сборки и зависимостей. Всё хранится в браузере, тёмная тема, удобно с телефона.

## Возможности

- **Колоды** с названием и описанием, карточки «вопрос — ответ», поиск по колоде.
- **Добавление списком**: вставьте строки `термин — определение`, и каждая строка станет карточкой. Разделителем может быть тире (—, –, -), табуляция (при копировании из Excel или Google Таблиц), `;`, `:` или `=`. Перед добавлением показывается превью и строки, которые не удалось разобрать. Нумерацию и маркеры списка в начале строк программа убирает сама, повторы пропускает.
- **Повторение по SM-2** с кнопками «Не помню», «Трудно» и «Легко». Под каждой кнопкой написано, когда карточка вернётся. Последний ответ можно отменить.
- **Тренировка**: прогон всех карточек колоды вперемешку без влияния на расписание. Удобно перед контрольной.
- **Лимит новых карточек в день** (по умолчанию 20 на колоду), чтобы повторения не копились лавиной.
- **Экспорт и импорт** колод в файл: резервная копия с прогрессом, файл «только карточки», чтобы поделиться, или текстовый список.
- Статистика: сколько карточек ждут повторения, сколько ответов сегодня, сколько дней подряд.
- Работает офлайн, если сайт открыт по http(s). Его можно установить на главный экран телефона.

### Колоды-примеры

| Колода | Карточек | Что внутри |
|---|---|---|
| Геометрия, 9 класс: формулы | 48 | теоремы синусов и косинусов, площади, тригонометрия, метод координат, векторы, правильные многоугольники, окружность и круг |
| Неправильные глаголы английского | 90 | инфинитив и перевод → три формы |
| Обществознание ОГЭ: термины | 73 | общество, человек, духовная сфера, экономика, социальная сфера, политика, право |

Удалённые примеры можно вернуть в «Настройках».

## Запуск

- **Локально**: откройте `index.html` в браузере. Всё работает и без сервера, кроме офлайн-режима.
- **С локальным сервером**: `npm start` (или `python3 -m http.server`), затем откройте http://localhost:8000.
- **GitHub Pages**: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Сайт появится по адресу `https://<пользователь>.github.io/flash-cards/`. Его можно открыть с телефона и добавить на главный экран.

## Как работает повторение (SM-2)

Каждая кнопка соответствует оценке качества ответа `q` по шкале SM-2:

| Кнопка | q | Что происходит |
|---|---|---|
| Не помню | 1 | счётчик повторений и интервал сбрасываются (интервал — 1 день), лёгкость уменьшается на 0,54; карточка ещё раз покажется в этой же сессии |
| Трудно | 3 | интервал растёт, лёгкость уменьшается на 0,14 |
| Легко | 5 | интервал растёт, лёгкость увеличивается на 0,1 |

При успешном ответе интервал равен 1 дню после первого повторения, 6 дням после второго, а дальше `предыдущий интервал × EF`. Коэффициент лёгкости EF вначале равен 2,5 и не опускается ниже 1,3. Формула: `EF' = EF + (0,1 − (5 − q)(0,08 + (5 − q)·0,02))`.

Расписание меняется только от первого ответа на карточку в сессии. Повторные показы после «Не помню» служат закреплению, как и предписывает SM-2.

## Данные, экспорт и импорт

Колоды и прогресс лежат в `localStorage` браузера (ключ `flashcards.v1`), только на этом устройстве. Чтобы перенести их на другое устройство или не потерять при очистке браузера, сохраняйте резервную копию через «Экспорт».

Формат файла экспорта:

```json
{
  "format": "flash-cards",
  "version": 1,
  "decks": [
    {
      "id": "…",
      "name": "Название",
      "description": "",
      "cards": [
        { "q": "Вопрос", "a": "Ответ", "ef": 2.5, "n": 0, "interval": 0, "due": null }
      ]
    }
  ]
}
```

Импорт понимает такой файл, а также упрощённые варианты:

- одну колоду `{ "name": "…", "cards": [...] }`;
- массив колод;
- массив карточек `[{ "q": "…", "a": "…" }]` или `[["вопрос", "ответ"]]`. Поля можно называть и `question`/`answer`, и `front`/`back`, и `term`/`definition`;
- текстовые файлы `.txt`, `.csv` и `.tsv`, где каждая строка — «вопрос — ответ». Поддерживаются кодировки UTF-8 и Windows-1251.

Если колода с таким же `id` уже есть, сайт спросит, заменить её или добавить копию.

В тексте карточки всё, что идёт после пустой строки, показывается мелким шрифтом как пояснение.
